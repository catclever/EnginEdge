# EnginEdge

[![Rust](https://img.shields.io/badge/Language-Rust-orange.svg)](https://www.rust-lang.org/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**Ultra-fast, native edge agent and Model Context Protocol (MCP) server for the Descartes & Dalembert ecosystem.**

- ⚡ **Native Performance**: Written in pure Rust for sub-millisecond execution and minimal memory footprint.
- 🌳 **Tree-sitter AST Engine**: AST-level code navigation, symbol inspection, and precision code replacement without line-number drift.
- 🔌 **Standard Model Context Protocol (MCP)**: Native stdio JSON-RPC server ready for Cursor, Claude Desktop, Antigravity, and Zed.
- 🌐 **Distributed Descartes Bridge**: Connects seamlessly over WebSocket to [Descartes Produit](https://github.com/catclever/descartes-produit) and [Dalembert](https://github.com/catclever/Dalembert).
